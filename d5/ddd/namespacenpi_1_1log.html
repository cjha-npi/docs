npi::log Namespace Reference

Description

Declares the logging category used for logging-system diagnostics.

The category is defined as npi.log by the logging implementation.

Runtime configuration and control API for the application logging system.

This namespace provides access to the current logging configuration and controls for file output, display output, field layouts, category filters, important-log forwarding, and console management.

Unless otherwise stated, configuration-changing and console-control functions are intended to be called from the GUI thread. State-query functions are synchronized and may be called from other threads.
