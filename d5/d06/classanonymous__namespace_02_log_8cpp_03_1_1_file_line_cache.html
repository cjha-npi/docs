anonymous_namespace{Log.cpp}::FileLineCache Class Referencefinal

Description

Caches normalized source-file and line-number text.

The cache keeps the last three path components when available, appends the source line, and stores the result in a fixed pool. Entries are addressed by compact 16-bit slots carried by OneLog.
