npi::wid::ColorPicker Class Reference

#include <ColorPicker.h>

Description

Widget for editing and previewing a color.

Supports RGB, HSL and HSV editing with a shared alpha channel. Config controls the selected color model, channel ranges and editing locks. Design controls the embedded widget's appearance and layout.

Only the selected model's channel limits and the alpha limits apply to the current color. Editing locks prevent user changes but do not prevent programmatic updates.

User edits emit colorChanged_() when the color changes.Programmatic setters do not emit the signal unless explicitly requested.

Use GetColor_() for modal color selection. The dialog uses Config but provides its own fixed presentation rather than accepting Design.
