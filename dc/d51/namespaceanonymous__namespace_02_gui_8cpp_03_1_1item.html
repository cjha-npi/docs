void anonymous_namespace{Gui.cpp}::item::applyBaseItem ( QWidget * wid)

Applies grouped-widget configuration to one widget.

Suppresses the widget's own background so the group base remains visible through it.

Note
  • Widgets marked with SunkenBase_ or RaisedBase_ are left unchanged.
  • Does not disable an existing Qt::WA_TranslucentBackground attribute.
  • Does nothing if the widget is null.

void anonymous_namespace{Gui.cpp}::item::applyViewItem ( QWidget * wid)

Applies item-view configuration to one widget.

Marks the widget as an item-view element, suppresses its own background, enables translucent-background handling and changes a Fixed vertical size policy to Expanding.

Note
Geometry and painting are refreshed when the internal item-view or no-background state is newly applied.
Does nothing if the widget is null.

If ButtonGroupBase_ is enabled, also makes immediate QPushButton and QToolButton children checkable and adds them to an exclusive QButtonGroup, reusing an existing direct-child group when available.

void anonymous_namespace{Gui.cpp}::item::setTransparentBase ( QWidget * wid,
bool itemViewWidget )

Configures a widget so its Base role does not obscure the underlying background.

Disables automatic background filling and sets the palette's Base brush to transparent. When requested, also enables WA_TranslucentBackground for use inside an item view.

Note
A false itemViewWidget argument does not clear Qt::WA_TranslucentBackground. This preserves item-view behavior when a widget also belongs to a grouped hierarchy.
Does nothing if the widget is null.
