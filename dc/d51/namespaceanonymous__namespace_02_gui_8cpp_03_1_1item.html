Initializes a widget marked as a ButtonGroupBase_.

Enables styled-background drawing on the base, disables automatic background filling and installs the hierarchy filter.

A direct child QButtonGroup is reused or created and made exclusive. Every direct QAbstractButton child is made checkable, configured as a group item and added to that button group if it is not already a member.

Note
Does nothing if either pointer is null or ButtonGroupBase_ is false.

Configures a widget so its Base role does not obscure the underlying background.

Disables automatic background filling and sets the palette's Base brush to transparent. When requested, also enables WA_TranslucentBackground for use inside an item view.

Note
A false translucent argument does not clear WA_TranslucentBackground. This preserves item-view behavior when a widget also belongs to a grouped hierarchy.
