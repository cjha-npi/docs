anonymous_namespace{Log.cpp} Namespace Reference

Description

Contains the private implementation of the logging system.

All symbols in this anonymous namespace are confined to this translation unit. The implementation is divided into focused internal namespaces for important-log bridging, crash handling, field layout, formatting, console control, workers, and runtime configuration.
