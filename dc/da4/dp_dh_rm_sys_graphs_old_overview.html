CJ_SysGraphs Skin

Introduction

CJ_SysGraphs is a Rainmeter skin that displays live CPU and RAM usage inside the empty horizontal area of the Windows taskbar. It is designed to behave like a compact taskbar widget rather than a normal desktop skin.

The skin automatically detects the usable taskbar space between the last visible taskbar button and the system tray, then resizes and positions itself inside that area. It shows per-logical-CPU usage bars, an overall CPU usage histogram, and a RAM usage histogram. Optional text labels can be toggled by double-clicking the skin.

The skin is made of a main Rainmeter .ini file, a native C++ plugin DLL, a Lua generation script, and two include files used for generated and stored data.

Displayed Information

CJ_SysGraphs displays three main types of system information:

Display Description
CPU bars One vertical bar for each logical CPU thread.
CPU histogram A compact graph showing overall CPU usage history.
RAM histogram A compact graph showing physical memory usage history.

The CPU bars provide a per-thread view, while the histograms provide a quick overview of recent CPU and RAM activity.

Optional text labels can show the CPU/RAM values and CPU bar indices. These labels are disabled by default and can be toggled by double-clicking the skin.

Taskbar-Based Layout

The skin is designed to occupy unused taskbar space. It does not use a fixed position or fixed width.

The native plugin calculates:

Value Meaning
BegX Start of the free taskbar area.
EndX End of the free taskbar area before the system tray.
BegY Top edge of the taskbar.
EndY Bottom edge of the taskbar.
Disp Whether the taskbar layout is supported.

Using these values, the skin calculates its own position, height, width, CPU bar width, and histogram width.

If the taskbar is vertical, the skin shows a warning and unloads itself because the layout is only intended for horizontal taskbars.

Automatic CPU Bar Generation

The number of CPU bars depends on the number of logical CPU threads on the system. Instead of manually writing a fixed number of CPU meters, the skin uses CJ_SysGraphs_GenCpuBars.lua.

The Lua script reads the system processor count and generates:

Generated section Purpose
MeasureCPU<n> Reads usage for one logical CPU thread.
MeterBarCPU<n> Displays the usage as a vertical bar.
MeterTextCPU<n> Displays the logical CPU number as text.

The generated content is written to CJ_SysGraphs_CpuBars.inc, which is then included by the main skin.

The script compares the new generated content with the existing include file before writing. This avoids unnecessary file writes and prevents repeated Rainmeter refreshes.

Dynamic Resizing

The skin continuously adapts to the available taskbar space.

When the free taskbar area changes, the skin recalculates:

Calculated value Purpose
Skin position Keeps the skin aligned with the free taskbar area.
Skin height Matches the taskbar height.
Skin width Fits inside the available taskbar space.
CPU bar width Shrinks or hides CPU bars when space is limited.
Histogram width Shrinks or hides histograms when space is limited.

This allows the skin to keep working when taskbar icons are added, removed, pinned, unpinned, opened, or closed.

Histogram Behavior

The CPU and RAM histograms are drawn using fixed-width backing meters and clipped by container meters.

This is important because Rainmeter histogram meters lose their history when their width changes. By keeping the actual histogram meter width fixed and only resizing the visible container, the skin can resize without losing the graph history.

Each histogram uses threshold-based coloring:

Usage level Meaning
Low Uses the minimum usage color.
Medium Uses the medium usage color.
High Uses the maximum usage color.

This makes high CPU or RAM usage easier to notice at a glance.

Theme Handling

The skin reads the Windows app theme setting and switches between light and dark color sets.

The active theme controls:

Variable type Purpose
Text color Color used for visible labels.
Minimum color Color used for low usage.
Medium color Color used for medium usage.
Maximum color Color used for high usage.

This allows the skin to visually match the current Windows light or dark theme.

Stored State

The skin uses CJ_SysGraphs_Stored.inc to save persistent values.

Currently, the stored value is:

Value Description
ShowText=0 Text labels are hidden.
ShowText=1 Text labels are visible.

This allows the skin to remember the text visibility state after refresh, reload, or Rainmeter restart.

User Interaction

The skin uses an almost-transparent full-size meter to detect double-clicks.

Double-clicking the skin toggles the text labels. The new value is saved to CJ_SysGraphs_Stored.inc, then the text meters are updated and the skin is redrawn.

The click-detection meter is drawn at the end of the file so it appears above all other meters and can reliably receive mouse input.

Position and Topmost Behavior

The skin is intended to stay locked to its calculated taskbar position. If it is moved away from that position, it moves itself back.

It also restores its topmost state if the Z-position changes. This keeps the skin visible above the taskbar area and prevents it from behaving like a normal movable desktop widget.

Practical Limitations

CJ_SysGraphs is designed for a normal horizontal Windows taskbar. It depends on Windows taskbar structure, Rainmeter behavior, and the native plugin's ability to read taskbar layout information.

The skin is not intended for vertical taskbars, heavily customized taskbar replacements, or layouts where Windows no longer exposes taskbar buttons and tray bounds in the expected way.
