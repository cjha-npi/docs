anonymous_namespace{Log.cpp}::workers Namespace Reference

Description

Owns asynchronous file and display processing and directory cleanup.

The file worker is the sole producer of the display queue. During shutdown it is therefore stopped and joined before the display worker, allowing all final records to be forwarded and drained deterministically.
