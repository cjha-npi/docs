Description

Application-wide cross-cutting non-domain specific code.

This namespace contains application-wide classes, structs, constants, variables, and functions that are not specific to any module or domain.

Note
Place domain-specific code in a dedicated namespace, such as npi::log.

const QString & message )
inlinenoexcept

Displays a Windows-native fatal error message box.

This function displays a modal Windows message box for fatal errors when QApplication might not be available, for example during application startup.

Parameters
titleThe title of the message box, "[AppName] Fatal Error:" is prepended to this.
messageThe message to display in the message box.
Warning
This function does not return; it calls std::abort() after displaying the message box.
