npi::app Namespace Reference

Description

Application-wide cross-cutting non-domain specific code.

This namespace contains application-wide classes, structs, constants, variables, and functions that are not specific to any module or domain.

Note
Place domain-specific code in a dedicated namespace, such as npi::log.
