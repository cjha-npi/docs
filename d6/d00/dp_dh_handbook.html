Deployment Check

A deployment check verifies that an application works outside Visual Studio without relying on development-machine paths or missing dependencies. The following procedure applies to Windows applications, including projects built with Qt.

1. Build the Entire Configuration

  • Select the intended configuration and architecture, for example Release / x64.
  • Rebuild the main application, required helper executables and project DLLs (if any).
  • Locate the resulting files in their configured output directories.

2. Prepare a Separate Deployment Folder

Create a new folder outside the source and build directories, for example D:\DeployCheck\MyApp. Copy the files required by the application to this folder:

  • Main application executable.
  • Helper executables, such as npiImpLog.exe and npiMsgBox.exe.
  • Project and third-party DLLs, external configuration, translations, templates or other required data.
Note
  • Place helper executables where the application expects to find them, commonly beside the main executable. Preserve any required subfolder structure.
  • Resources compiled into an executable through Qt resources do not need separate copies. External files and binary resource files loaded at runtime must be included.

3. Deploy Qt Dependencies

For applications using shared Qt libraries, use windeployqt from the same Qt kit used to build the application. It collects Qt DLLs and plugins into the deployment folder. See Qt Windows Deployment. Run command in either command prompt or powershell, replacing the paths as needed:

Command Prompt:

"C:\Qt\6.12.0\msvc2022_64\bin\windeployqt.exe" --release "D:\DeployCheck\MyApp\MyApp.exe"

Powershell:

& "C:\Qt\6.12.0\msvc2022_64\bin\windeployqt.exe" --release "D:\DeployCheck\MyApp\MyApp.exe"
  • Check the command output for missing dependencies or other errors.
  • Keep the generated plugin folders, including platforms.
  • Repeat dependency deployment for any helper executable that also uses Qt.
Warning
  • Qt libraries and plugins must match the application's Qt kit and architecture.
  • Do not mix Debug and Release Qt binaries or files from different Qt installations.

4. Check Functionality

Launch the copied main executable directly from File Explorer, without using Visual Studio or a Qt development command prompt.

Note
For a stronger check, copy the complete deployment folder to a clean Windows machine or virtual machine without Qt or Visual Studio installed. Install only the documented prerequisites, including the appropriate Microsoft Visual C++ Redistributable.

Verify the features relevant to the project:

  • Application starts and closes normally.
  • Icons, fonts, images and translations load correctly.
  • File and folder dialogs work.
  • Configuration and data can be read and saved.
  • Required helper processes launch and perform their intended work.
  • Logging creates the expected files, including helper-managed output where applicable.
  • Features using optional plugins or third-party libraries work.

Also launch the application with a different working directory. Required files should be located according to the application's intended path rules, not accidentally through the source or build directory.

Create ICO Icons Using ImageMagick

Create a multi-size .ico file from a .png or other type of file using ImageMagick. The ImageMagick is an open-source software suite, used for editing and manipulating digital images. To install:

  1. Go to official ImageMagick Download Page
  2. Download the current Q16 (16 bits-per-pixel) x64 DLL .exe installer e.g. ImageMagick-7.1.2-23-Q16-HDRI-x64-dll.exe
  3. Run the installer, during installation, enable these options if shown:
    • Add application directory to your system path
    • Install legacy utilities
  4. Verify: In a Command Prompt magick -version or magick identify -version.

Usage

Make sure the input image:

  • is at least 512x512 with square aspect ratio
  • has transparent background if possible

Use the following command in a command prompt and change input.png and output.ico as required.

magick input.png -define icon:auto-resize=256,128,64,48,32,24,16 output.ico

ImageMagick will resize the original .png into all those sizes and pack them into one .ico file.

Create Files with Given Size

For testing it is sometimes necessary to create files with a given size in a folder, open command prompt in a folder and use:

1 KiB:

fsutil file createnew file_name.txt 1024

1 MiB:

fsutil file createnew file_name.txt 1048576

10 MiB:

fsutil file createnew file_name.txt 10485760

100 MiB:

fsutil file createnew file_name.txt 104857600

1 GiB:

fsutil file createnew file_name.txt 1073741824
