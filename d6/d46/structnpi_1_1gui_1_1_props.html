npi::gui::Props Struct Referencefinal

#include <Gui.h>

Description

Dynamic property names for specialized GUI behavior.

Set these properties using QObject::setProperty() or as dynamic properties in Qt Designer using property string names. Each property documents its expected value type and supported widgets.

Note
Unless otherwise stated, set properties before the widget is polished by the application style. If the widget is already polished, call widget->style()->polish(widget) after setting the property.
Warning
Removing a property does not necessarily undo its configuration. In particular, group-base and item-view configuration may permanently alter widget backgrounds, sizing or button grouping. Polishing again does not restore the original configuration.

staticconstexpr

QColor - Makes a QPushButton display the specified color.

Replaces normal button visuals with a color preview over a white and gray checkerboard to show transparency. Text, icons and pressed, focus and default-button indicators are not drawn. When disabled, the color is shown in grayscale while preserving its alpha.

Note
Set the property before polishing. Its color value can then be changed at runtime, with automatic repainting.
Warning
Changes the focus policy to Qt::NoFocus but does not disable mouse interaction or the clicked() signal. Removing the property does not restore the previous focus policy.

const char* npi::gui::Props::ButtonGroupBase_ {"npi_ButtonGroupBase"}
staticconstexpr

bool - Provides a shared background with exclusive button grouping.

Immediate QPushButton and QToolButton children are made checkable and added to an exclusive QButtonGroup. An existing direct-child group is reused; otherwise one is created. Children added later are handled automatically.

Descendant backgrounds are suppressed unless they have SunkenBase_ or RaisedBase_ enabled. Configuration does not extend into child windows.

Note
  • Uses a rounded Surfaces::raised_ background unless SunkenBase_ is enabled.
  • When nested inside another group base, its background is suppressed unless SunkenBase_ or RaisedBase_ is also enabled.
  • Item-view background handling takes precedence.
  • After changing this property at runtime, manually polish the base widget.
Warning
Removing this property does not undo button grouping, checkability or background configuration. Configured descendants are not intended to be reparented and reused as ordinary widgets outside the group.

◆ IconName_

const char* npi::gui::Props::IconName_ {"npi_IconName"}
staticconstexpr

QString - Resource name for a theme-dependent icon or label pixmap.

Specify the name without a path or extension. Resource lookup uses :/icons/dark/<name>.png or :/icons/light/<name>.png, according to the effective background. If unavailable, :/icons/<name>.png is used.

Note
  • Applies to QAbstractButton, QAction and QLabel.
  • For buttons and actions, this supplies the QIcon::Off state. Use IconOnName_ for the QIcon::On state.
  • Icons are refreshed when the effective dark/light background changes.
  • Set action properties before adding the action to its GUI control.
Warning
If neither resource exists, a warning is logged. Buttons and actions fall back to the corresponding Normal-mode pixmaps from the icon stored on their first dynamic-icon update. Labels retain their current pixmap.

bool - Marks a widget for use inside an item view.

Configures the marked widget and its descendants for item-view background handling and sizing. Children added later are handled automatically. Configuration does not extend into child windows.

Note
  • Set this on the root widget before calling setCellWidget(), setItemWidget() or setIndexWidget(), and before the widget is polished.
  • Descendants do not need this property.
  • Item-view background handling takes precedence over group-base styling.
Warning
Removing this property does not restore the original configuration. Configured widgets are not intended to be reparented and reused as ordinary widgets outside an item view.

const char* npi::gui::Props::SepBorders_ {"npi_SepBorders"}
staticconstexpr

QString - Selects separator borders for backgroundless controls.

Use T (top), R (right), B (bottom) and L (left), in any combination and case. For example, "TB" draws top and bottom separators. Separator ends are inset from the corners.

Note
  • Applies to QPushButton, QToolButton, QComboBox, QLineEdit and QAbstractSpinBox when their backgrounds are suppressed by group-base or item-view configuration.
  • On a QFrame with HLine or VLine shape, the property's presence requests inset line ends; its string value is ignored.
  • Supports runtime changes without polishing. Call QWidget::update() after changing the property to schedule a repaint.

staticconstexpr

bool - Forwards wheel input to the widget's parent.

When enabled and a parent widget exists, wheel events are forwarded to that parent instead of being handled by this widget. Useful for preventing wheel input from changing a control's value while allowing its surrounding container to scroll.

Note
  • If no parent widget exists, normal wheel handling is preserved.
  • The original event is consumed even if the parent ignores it.

◆ WidthSameAsHeight_

const char* npi::gui::Props::WidthSameAsHeight_ {"npi_WidthSameAsHeight"}
staticconstexpr

bool - Requests a width equal to the widget's calculated height.

Adjusts the style's size hint to request square sizing. The width remains constrained by minimumWidth() and maximumWidth().

Note
  • Menu-free, icon-only QPushButton controls and QToolButton controls displaying only an icon or arrow request square sizing automatically. Tool buttons directly inside QLineEdit are excluded from this automatic behavior.
  • This affects the size hint, not a fixed size; the layout may assign different dimensions.
Warning
Does not apply to QLabel or widgets configured as item-view widgets.
