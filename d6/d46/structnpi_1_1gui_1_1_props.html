#include <Gui.h>

Description

QObject dynamic properties providing special GUI functionality.

Note
  • Unless otherwise stated, these properties should be set before the widget is polished by the application style. If that cannot be guaranteed, manually polish the widget after setting the property.
  • ButtonColorDisplay_ is the only property whose value is intended to change dynamically at runtime after initialization.

const char* npi::gui::Props::ButtonColorDisplay_ {"npi_ButtonColorDisplay"}
staticconstexpr

QColor - Makes a QPushButton display the specified color.

The button is drawn as a color display rather than with normal button visuals: text, icon and pressed/focus/default visual states are not drawn. When disabled, the displayed color is converted to grayscale.

Note
The property should be present before polish, but its QColor value may be changed dynamically afterward and the button will repaint automatically.
Warning
The button's focus policy is changed to Qt::NoFocus.

const char* npi::gui::Props::ButtonGroupBase_ {"npi_ButtonGroupBase"}
staticconstexpr

bool - Makes a widget the visual base for grouped exclusive buttons.

The base is drawn as a single button-colored rounded surface. If a layout exists when the base is polished, its margins and spacing are set to zero. Direct button children are made checkable and added to one exclusive QButtonGroup. An existing direct QButtonGroup is reused; otherwise one is created automatically.

Note
Buttons may be added and removed dynamically at runtime.
Warning
  • Buttons configured as part of this group are not intended to be removed, reparented and reused as ordinary widgets.
  • Only QPushButton and QToolButton should be used as direct widget children.

◆ IconName_

const char* npi::gui::Props::IconName_ {"npi_IconName"}
staticconstexpr

QString - Name of the theme-dependent icon without path or extension.

The active theme-specific resource is searched first: :/icons/dark/<name>.png for the dark theme or :/icons/light/<name>.png for the light theme. If that resource does not exist, :/icons/<name>.png is used as the fallback.

Note
  • If neither resource exists, a warning is logged. Buttons and actions use the stored original icon's corresponding state as fallback; labels retain their existing pixmap.
  • Only applies to QAbstractButton, QLabel and QAction.

const char* npi::gui::Props::ItemViewWidget_ {"npi_ItemViewWidget"}
staticconstexpr

bool - Marks a widget intentionally installed as an item-view widget.

The marked root widget and its descendants are configured for correct background handling, sizing and runtime child handling inside an item view.

Note
Set this on the root widget before using setCellWidget(), setItemWidget() or setIndexWidget(), and before the widget is polished, preferably immediately after creating the widget. Descendants are handled automatically.
Warning
A widget configured as an item-view widget, or one of its configured descendants, is not intended to be removed and reparented for reuse as an ordinary widget.

Sets password echo mode, installs the application password validator, enables the clear button and adds a leading action to show/hide the password. Accepted characters are A-Z, a-z, 0-9, !, $, ^, &, *, # and _, with a maximum accepted length of 32 characters.

◆ WidgetGroupBase_

const char* npi::gui::Props::WidgetGroupBase_ {"npi_WidgetGroupBase"}
staticconstexpr

bool - Makes a widget the visual base for a group of child widgets.

The base is drawn as a single button-colored rounded surface. If a layout exists when the base is polished, its margins and spacing are set to zero. Descendant widgets are configured not to draw their own background so the group appears as one control.

Note
Widgets may be added and removed dynamically at runtime.
Warning
  • Widgets configured as part of this group are not intended to be removed, reparented and reused as ordinary widgets.
  • This property does not make button children exclusive or place them in a QButtonGroup. Use ButtonGroupBase_ for that functionality.

◆ WidthSameAsHeight_

const char* npi::gui::Props::WidthSameAsHeight_ {"npi_WidthSameAsHeight"}
staticconstexpr

bool - Requests a widget width equal to its calculated height.

Note
  • Menu-free icon-only QPushButton controls and QToolButton controls displaying only an icon or arrow request square sizing automatically. Tool buttons directly inside QLineEdit are excluded.
  • The resulting width is constrained by the widget's minimumWidth() and maximumWidth().
Warning
Does not apply to widgets inside QAbstractItemView or to QLabel.
