npi::gui::Props Struct Referencefinal

#include <Gui.h>

Description

Dynamic property names for specialized widget behavior.

Set using QObject::setProperty() or property strings in Designer. Unless stated otherwise, set before polishing; for an existing widget, call widget->style()->polish(widget) after setting the property.

Note
  • Group-base settings cover descendants and later additions, but stop at child windows.
  • Item-view configuration takes precedence.
Warning
Removing properties or repolishing does not necessarily restore original backgrounds, sizing, focus policies or button grouping.

const char* npi::gui::Props::ButtonDisplay_ {"npi_ButtonDisplay"}
staticconstexpr

QVariant - Overrides QPushButton and QToolButton background drawing.

Presence enables display mode, including a value of false:

  • Convertible to valid QColor: fills over a transparency checkerboard; disabled colors become grayscale with alpha preserved.
  • Otherwise: no fill; an iconless, textless button gets a thin raised-color border. Content, menu indicators and npi::gui::Props::SepBorders_ remain; normal background-state effects and focus indicators are omitted. Sizing is unchanged.
Note
Set before polishing. Subsequent value changes/removal repaint automatically. Removal restores normal drawing. Qt-managed internal buttons can be exempt.
Warning
  • Polishing applies Qt::NoFocus without disabling button interaction.
  • Removing the property does not restore the previous focus policy.

const char* npi::gui::Props::ButtonGroupBase_ {"npi_ButtonGroupBase"}
staticconstexpr

bool - Provides a shared background with exclusive button grouping.

Immediate QPushButton and QToolButton children become checkable and join an exclusive QButtonGroup. An existing direct-child group is reused. Tool buttons with checkable default actions in an exclusive QActionGroup are excluded. Uses the raised background unless npi::gui::Props::SunkenBase_ is enabled; nesting follows the group-base rules in GUI Systems documentation.

Note
No initial selection is imposed. Repolish the base to reevaluate grouping. See GUI Systems documentation for action assignment and runtime restrictions.
Warning
Reused groups become managed and exclusive. Removing the property does not undo grouping, checkability or background configuration.

const char* npi::gui::Props::IconName_ {"npi_IconName"}
staticconstexpr

QString - Resource name for a themed icon or label pixmap.

Applies to QAbstractButton, QAction and QLabel. Specify a name without path or extension. Uses the effective background's dark/light icons directory, falling back to the common icon directory.

Note
  • Supplies QIcon::Off for buttons/actions; npi::gui::Props::IconOnName_ supplies QIcon::On.
  • Refreshes on background changes. Repolish the button, label or action's containing widget for immediate refresh after changing the property.
  • Configure action properties before attaching the action to its widget.
Warning
  • Clearing the properties does not restore the original icon.
  • Resource paths and fallback details are in GUI Systems documentation.

bool - Configures an embedded item-view widget and its descendants.

Suppresses backgrounds and changes Fixed vertical size policies to Expanding. Later children are handled; child windows are excluded.

Note
Set on the root before setCellWidget(), setItemWidget() or setIndexWidget(). If set later, repolish the owning item view, not just the embedded widget.
Warning

bool - Requests a width equal to the calculated height.

Adjusts supported size hints within minimum/maximum width constraints. Layouts may assign different dimensions; this is not a fixed size. Menu-free icon-only QPushButton controls and icon-only QToolButton controls without MenuButtonPopup request square sizing automatically.

Note
