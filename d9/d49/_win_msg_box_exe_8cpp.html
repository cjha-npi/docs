Description

Implements helper-process based Windows message boxes.

This file launches npiMsgBox.exe to show native Windows message boxes from a separate process. This allows information and warning messages to be shown without blocking the caller thread.

The stop message variant launches the helper process and then terminates the current process. This is intended for known fatal paths where the caller wants to show a final message but does not want normal shutdown or CRT abort handling.

The command line passed to npiMsgBox.exe has the form: "full\path\to\npiMsgBox.exe" "Application Title" "Message" "Severity"

Severity:

  • 0 = information
  • 1 = warning
  • 2 = stop/error

Message text is sanitized before being appended to the command line. Unsupported characters are replaced, quotes are converted to apostrophes, and backslashes are converted to forward slashes to avoid command-line parsing issues.
