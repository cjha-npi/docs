Description

RAII locker for a session-local Windows named mutex.

Defines npi::app::CrossProcessLocker, a small RAII helper that creates or opens a Windows named mutex, waits for ownership, releases ownership, and closes the mutex handle.

A named mutex can synchronize access between:

  • Multiple threads within one process.
  • Multiple processes running in the same Windows session.

Scope:

  • The constructor prepends "Local\\" to the provided name, limiting visibility to the current Windows session. - A "Global\" prefix would place the mutex in the global namespace, subject to the mutex object's access-control settings.

Ownership:

  • Successful construction guarantees ownership of the mutex.
  • Invalid input or any mutex creation/acquisition failure terminates the application through an out-of-process stop-message helper.
  • Destruction releases ownership and closes the mutex handle.

Abandoned mutexes:

  • WAIT_ABANDONED is treated as successful acquisition, as required by Windows mutex semantics.
  • A warning is logged because the protected resource may be inconsistent.
  • wasAbandoned_() allows the caller to detect this condition and perform any required validation or recovery.
Warning
Invalid input or failure to create or acquire the mutex causes immediate application termination.
