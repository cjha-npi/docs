anonymous_namespace{Gui.cpp}::GuiStyle Class Referencefinal

Description

Application style implementing the GUI system.

GuiStyle uses Fusion through QProxyStyle and customizes widget initialization, sizing, drawing and event handling to provide a consistent application appearance.

It also implements QAbstractNativeEventFilter to observe Windows theme-setting changes. While Theme::System is selected, a relevant Windows setting change updates the effective dark/light palette and theme-dependent icons.

Calculates customized content sizes for supported controls.

Adds vertical space to item-view items and makes their heights even, adjusts menu-item heights, standardizes fixed-height controls, and applies square sizing and custom QPushButton layout requirements. Embedded item-view widgets and internal child controls retain base-style sizing.

Note
  • QLabel does not obtain its size through this function.
  • Qt caches most widget size hints. Send a StyleChange event when an immediate recalculation is required after a change that does not invalidate the cached size automatically.
