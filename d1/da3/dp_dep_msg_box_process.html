Msg Box Process

Introduction

The npiMsgBox.exe is a small helper executable used to show native Windows message boxes from a separate process.

It is mainly used when the main application should not block on MessageBoxW(). The parent process starts npiMsgBox.exe, passes the message data through the command line, and then either continues execution or terminates, depending on the message type.

This is useful for fatal or stop paths because showing a message box directly inside the main process would block the calling thread while the rest of the application may continue running. That can cause repeated errors, additional logging, or shutdown complications. By using a separate process, the parent application can launch the message box and immediately continue or terminate.

Demo Project: D142_npiMsgBox_Exe

Requirements

  • Application name through npi::app::appName, this is used as the title of the message box (for easier identification).
  • The npiMsgBox.exe being in the same directory as main application executable. Since, the path to npiMsgBox.exe is determined using the full path of application executable.

Executable

The helper executable is named:

npiMsgBox.exe

The parent application expects this executable to be located in the same directory as the parent application executable. The helper process receives its data through command-line arguments.

Expected format:

"full\path\to\npiMsgBox.exe" "Title" "Message" "Severity"

Arguments:

  • Title: Message box title.
  • Message: Message box text.
  • Severity: Message box type.
    • 0 = Information message
    • 1 = Warning message
    • 2 = Stop/error message

Severity 0 uses an information icon.

Severity 1 uses a warning icon.

Severity 2 uses an error icon and system-modal behavior so the final stop message is more likely to stay visible even when the parent process terminates immediately after launching the helper.

Parent Side

Calling Functions:

The parent application uses the functions declared in WinMsgBoxExe.h.

void winInfoMsgExe(const char* message) noexcept;
void winInfoMsgExe(QStringView message) noexcept;
void winWarnMsgExe(const char* message) noexcept;
void winWarnMsgExe(QStringView message) noexcept;
[[noreturn]] void winStopMsgExe(const char* message) noexcept;
[[noreturn]] void winStopMsgExe(QStringView message) noexcept;

The information and warning functions launch npiMsgBox.exe and return.

The stop functions launch npiMsgBox.exe and then terminate the current process.

Message Sanitization:

  • The parent process sanitizes the title and message before passing them to npiMsgBox.exe.
  • The command line uses double quotes to separate arguments, so embedded double quotes are replaced with apostrophes.
  • Backslashes are replaced with forward slashes to avoid command-line parsing ambiguity near quotes.
  • Unsupported control or non-ASCII characters are replaced with ?.
  • Newlines are preserved in message text.
  • Tabs are converted to spaces.

Thread Behavior:

The command-line prefix is prepared once and reused.

The prefix contains:

"full\path\to\npiMsgBox.exe" "Title" "

Information and warning calls copy this prefix into a local stack buffer before appending the message. This allows multiple callers to show non-fatal messages without modifying the shared command-line buffer.

Stop messages use a first-call-wins guard. The first stop call launches the helper process and terminates the current process. Later stop calls terminate immediately.

Process Launching:

  • The parent process starts the helper using CreateProcessW().
  • The full path to npiMsgBox.exe is passed as lpApplicationName.
  • The command line is passed as a mutable wide-character buffer because CreateProcessW() may modify the command-line buffer.
  • The helper is launched with CREATE_NO_WINDOW, which suppresses a console window but does not suppress the native message box.

Foreground Handling:

After successfully creating the helper process, the parent calls AllowSetForegroundWindow() for the helper process ID. This allows the helper process to bring its message box to the foreground.

For stop/error messages, npiMsgBox.exe also uses MB_SYSTEMMODAL to make the final message more visible when the parent process terminates immediately.

Failure Behavior:

  • If the helper process cannot be prepared or launched, information and warning calls simply return without showing a message.
  • Stop calls always terminate the current process, even if the helper message box cannot be launched.
  • The stop functions call TerminateProcess() and then std::abort() as a fallback to satisfy the [[noreturn]] contract.

Limitations

  • The message is passed through the command line, so the maximum message length is limited by the command-line buffer used by the parent implementation.
  • The current implementation intentionally keeps the protocol simple. It does not use pipes, temporary files, shared memory, or Base64 encoding.
  • The helper process is intended for short diagnostic messages, warnings, and final stop/error messages. It is not intended for large reports or structured diagnostic data.

/**
* \file npiMsgBox.cpp
* \brief Implements the `npiMsgBox.exe` helper process.
*
* \details
* This executable shows a native Windows message box from a separate process.
* It is intended for fire-and-forget messages where the caller should not block.
*
* Expected command line:
* "full\path\to\npiMsgBox.exe" "Title" "Message" "Severity"
*
* Severity:
* - 0 = information
* - 1 = warning
* - 2 = error / stop
*
* The parent process is responsible for sanitizing command-line arguments before
* launching this executable.
*/
#ifndef NOMINMAX
#define NOMINMAX
#endif
#ifndef WIN32_LEAN_AND_MEAN
#define WIN32_LEAN_AND_MEAN
#endif
#ifndef STRICT
#define STRICT
#endif
#include <Windows.h>
#include <cstdlib>
int wmain(int argc, wchar_t* argv[]) noexcept
{
const wchar_t* title = L"Message";
const wchar_t* message = L"No message provided.";
const wchar_t* severity = L"0";
if(argc >= 3) {
if(argv[1] && argv[1][0] != L'\0')
title = argv[1];
if(argv[2] && argv[2][0] != L'\0')
message = argv[2];
}
if(argc >= 4 && argv[3] && argv[3][0] != L'\0')
severity = argv[3];
// info (default)
UINT boxType = MB_OK | MB_ICONINFORMATION | MB_TOPMOST | MB_SETFOREGROUND;
if(severity[0] == L'1') {
// warning
boxType = MB_OK | MB_ICONWARNING | MB_TOPMOST | MB_SETFOREGROUND;
}
else if(severity[0] == L'2') {
// error/stop
boxType = MB_OK | MB_ICONERROR | MB_TOPMOST | MB_SETFOREGROUND | MB_SYSTEMMODAL;
}
::MessageBoxW(nullptr, message, title, boxType);
return argc >= 3 ? EXIT_SUCCESS : EXIT_FAILURE;
}

#ifndef NOMINMAX
#define NOMINMAX
#endif
#ifndef WIN32_LEAN_AND_MEAN
#define WIN32_LEAN_AND_MEAN
#endif
#ifndef STRICT
#define STRICT
#endif
#include <Windows.h>
#include <atomic>
#include <cstdlib>
#include <cstddef>
#include "src/Root/MetaInfo.h"
#include "WinMsgBoxExe.h"
/**
* \brief Helper namespace for `npiMsgBox.exe` calls.
*/
namespace
{
/// \brief Maximum full executable path length used by this module.
constexpr size_t exePathMax = 4096u;
/// \brief Command-line buffer maximum length: exe path + text + title/type overhead.
constexpr size_t cmdLineMax = exePathMax + 4096u + 2048u;
/// \brief Fixed helper exe name.
/// The current application's exe name is replaced with
/// this name to launch the helper exe.
/// \note For this to work, application exe and the helper
/// exe should be in the same directory.
constexpr wchar_t msgBoxExeName[] = L"npiMsgBox.exe";
/// \brief Buffer to store application exe full path.
wchar_t appExeFullPath[exePathMax]{};
/// \brief Buffer to store full path to `npiMsgBox.exe`.
wchar_t exePathBuf[exePathMax]{};
/// \brief Buffer to pass as command line to helper exe.
/// This is filled with
/// `"full\path\to\npiMsgBox.exe" "Application Title" "`
/// on first use. Any info/warning message uses this
/// and fills up its own buffer then appends message
/// and severity. For fatal/stop messages this buffer
/// is used directly to avoid allocation in such cases.
wchar_t cmdLineBuf[cmdLineMax]{};
/// \brief Position of the null terminating character in exePathBuf.
size_t exePathPos{0};
/// \brief Position of the null terminating character in cmdLineBuf.
size_t cmdLinePos{0};
/// \brief Set to true after exePathBuf/cmdLineBuf prefix has been built on first call.
std::atomic_bool prefixPrepared{false};
/// \brief Prevents multiple threads from trying to fill exePathBuf/cmdLineBuf.
/// If multiple threads call the first time simultaneously, this variable prevents
/// the exePathBuf/cmdLineBuf from filling up simultaneously.
std::atomic_bool prefixPreparing{false};
/// \brief Variable to stop second and further calls of stop message from generating message box.
/// Only the first call to winStopMsgExe() shows the message box. If by chance a second call is
/// made to winStopMsgExe before the first one can terminate the process then this variable stops
/// the second call from generating a message and terminates the process immediately.
std::atomic_bool stopProcessed{false};
/// \brief Appends one character to the prepared executable path buffer.
bool exePathBufAppend(wchar_t chr) noexcept
{
if(exePathPos + 1u < exePathMax) {
exePathBuf[exePathPos++] = chr;
exePathBuf[exePathPos] = L'\0';
return true;
}
return false;
}
/// \brief Appends one character to the prepared command-line prefix buffer.
bool cmdLineBufAppend(wchar_t chr) noexcept
{
if(cmdLinePos + 1u < cmdLineMax) {
cmdLineBuf[cmdLinePos++] = chr;
cmdLineBuf[cmdLinePos] = L'\0';
return true;
}
return false;
}
/// \brief Sanitizes and appends one title character to the command-line prefix.
bool cmdLineBufAppendTitleChar(unsigned int uChr) noexcept
{
if(cmdLinePos + 1u >= cmdLineMax) return false;
if(uChr < 32u || uChr > 126u) cmdLineBuf[cmdLinePos++] = L'?';
else if(uChr == '"') cmdLineBuf[cmdLinePos++] = L'\'';
else if(uChr == '\\') cmdLineBuf[cmdLinePos++] = L'/';
else cmdLineBuf[cmdLinePos++] = static_cast<wchar_t>(uChr);
cmdLineBuf[cmdLinePos] = L'\0';
return true;
}
/// \brief Appends the application title used as the message-box title to the command-line prefix.
bool cmdLineBufAppendTitle() noexcept
{
const char* data = npi::app::appName.data();
const qsizetype size = npi::app::appName.size();
for(qsizetype ii = 0; ii < size; ++ii) {
if(!cmdLineBufAppendTitleChar(static_cast<unsigned char>(data[ii])))
return false;
}
return true;
}
/// \brief Builds the helper executable path and reusable command-line prefix.
/// The command-line prefix buffer is filled with
/// `"full\path\to\npiMsgBox.exe" "Application Title" "`
/// This enables for further messages to just append message and severity
/// before using the full command line buffer. Info and warning messages
/// use their own temporary buffers, while fatal/stop messages use the
/// command line buffer (since it avoids allocation and only one fatal/stop
/// message can produce a message).
/// \note This function is guarded because the prefix buffers are shared.
bool prepare() noexcept
{
if(prefixPrepared.load(std::memory_order_acquire))
return true;
bool expected = false;
// Another thread is already preparing the shared prefix.
if(!prefixPreparing.compare_exchange_strong(expected, true, std::memory_order_acq_rel))
return false;
auto fail = []() noexcept {
prefixPreparing.store(false, std::memory_order_release);
return false;
};
exePathPos = 0;
cmdLinePos = 0;
const DWORD n = ::GetModuleFileNameW(nullptr, appExeFullPath, exePathMax);
if(n == 0 || n >= exePathMax)
return fail();
// Find the directory of the current executable and place npiMsgBox.exe next to it.
size_t sep = 0;
for(size_t ii = 0; ii < n; ++ii) {
if(appExeFullPath[ii] == '\\' || appExeFullPath[ii] == '/')
sep = ii;
}
if(sep == 0 || sep == n) return fail();
if(!cmdLineBufAppend(L'\"')) return fail();
for(size_t ii = 0; ii < sep + 1; ++ii) {
if(!exePathBufAppend(appExeFullPath[ii])) return fail();
if(!cmdLineBufAppend(appExeFullPath[ii])) return fail();
}
for(size_t ii = 0; msgBoxExeName[ii] != L'\0'; ++ii) {
if(!exePathBufAppend(msgBoxExeName[ii])) return fail();
if(!cmdLineBufAppend(msgBoxExeName[ii])) return fail();
}
if(!cmdLineBufAppend(L'\"')) return fail();
if(!cmdLineBufAppend(L' ')) return fail();
if(!cmdLineBufAppend(L'\"')) return fail();
if(!cmdLineBufAppendTitle()) return fail();
if(!cmdLineBufAppend(L'\"')) return fail();
if(!cmdLineBufAppend(L' ')) return fail();
if(!cmdLineBufAppend(L'\"')) return fail();
prefixPrepared.store(true, std::memory_order_release);
return true;
}
/// \brief Copies the prepared command-line prefix into a per-call buffer.
/// \details Info/warning messages use a local buffer so multiple callers do not modify shared state.
void copyCmdLineBuf(wchar_t* buf, size_t& pos) noexcept
{
pos = 0;
for(size_t ii = 0; ii < cmdLinePos; ++ii)
buf[pos++] = cmdLineBuf[ii];
buf[pos] = L'\0';
}
/// \brief Sanitizes and appends one message character.
/// \details Keeps one extra character available so the final quote and null terminator can be appended.
bool bufAppendMsgChar(wchar_t* buf, size_t& pos, unsigned int uChr) noexcept
{
if(pos + 2u >= cmdLineMax) return false;
if(uChr == '\n') buf[pos++] = L'\n';
else if(uChr == '\t') buf[pos++] = L' ';
else if(uChr < 32u || uChr > 126u) buf[pos++] = L'?';
else if(uChr == '"') buf[pos++] = L'\'';
else if(uChr == '\\') buf[pos++] = L'/';
else buf[pos++] = static_cast<wchar_t>(uChr);
buf[pos] = L'\0';
return true;
}
/// \brief Appends a null-terminated ASCII message to the command line.
void bufAppendMsg(wchar_t* buf, size_t& pos, const char* text) noexcept
{
if(!text) return;
while(*text) {
if(!bufAppendMsgChar(buf, pos, static_cast<unsigned char>(*text)))
break;
++text;
}
}
/// \brief Appends a Qt UTF-16 message to the command line after ASCII sanitization.
void bufAppendMsg(wchar_t* buf, size_t& pos, QStringView text) noexcept
{
for(const QChar& chr : text) {
if(!bufAppendMsgChar(buf, pos, static_cast<unsigned int>(chr.unicode())))
break;
}
}
/// \brief Finalizes the command line and launches npiMsgBox.exe.
/// \param type 0 = information, 1 = warning, 2 = stop/error.
void launch(wchar_t* buf, size_t pos, int type = 0) noexcept
{
if(pos + 5u >= cmdLineMax) return;
// Close the message argument, then append the severity argument.
buf[pos++] = L'"';
buf[pos++] = L' ';
buf[pos++] = L'"';
if(type == 0) buf[pos++] = L'0';
else if(type == 1) buf[pos++] = L'1';
else if(type == 2) buf[pos++] = L'2';
buf[pos++] = L'"';
buf[pos] = L'\0';
STARTUPINFOW si{};
si.cb = sizeof(si);
PROCESS_INFORMATION pi{};
if(::CreateProcessW(
exePathBuf, // lpApplicationName: full path to npiMsgBox.exe
buf, // lpCommandLine: "exe" "title" "message" "type"
nullptr,
nullptr,
FALSE,
CREATE_NO_WINDOW,
nullptr,
nullptr,
&si,
&pi)) {
// Allows the helper process to bring its message box to the foreground.
::AllowSetForegroundWindow(pi.dwProcessId);
::CloseHandle(pi.hThread);
::CloseHandle(pi.hProcess);
}
}
}
void npi::app::winInfoMsgExe(const char* message) noexcept
{
if(message != nullptr && prepare()) {
wchar_t buf[cmdLineMax]{};
size_t pos{0};
copyCmdLineBuf(buf, pos);
bufAppendMsg(buf, pos, message);
launch(buf, pos, 0);
}
}

[[noreturn]] void npi::app::winStopMsgExe(const char* message) noexcept
{
if(!stopProcessed.exchange(true, std::memory_order_acq_rel) && message != nullptr && prepare()) {
bufAppendMsg(cmdLineBuf, cmdLinePos, message);
launch(cmdLineBuf, cmdLinePos, 2);
}
::TerminateProcess(::GetCurrentProcess(), EXIT_FAILURE);
std::abort(); // fallback to satisfy the [[noreturn]] contract.
}
