anonymous_namespace{Log.cpp}::crash Namespace Reference

Description

Installs and implements fatal and abnormal-termination handling.

Handlers avoid dynamic allocation where practical, claim a single fatal owner, format emergency diagnostics into fixed buffers, forward them to the important log helper, and terminate the process without re-entering ordinary logging.

Note
Crash handlers intentionally do not show message boxes. They only write a small best-effort crash record and then terminate or preserve default crash behavior. UI/reporting from these paths should be done by an external process.
