Description

Declares runtime configuration and public controls for the graphical user interface.

The GUI system provides a centralized application style with dark, light, and system-following themes. This file exposes functions for selecting and querying the current theme, determining the effective dark/light background, and retrieving GUI colors for the current or an explicitly selected background.

This file also declares QObject dynamic properties used to request specialized widget behavior, including theme-dependent icons, password line edits, item-view widgets, square sizing, grouped widgets and buttons, custom QPushButton layout, color-display buttons, and wheel-event forwarding.

Unless otherwise documented, GUI properties are intended to be set before the widget is polished by the application style. Properties that require initialization after being set must be applied through a subsequent manual polish when that timing cannot be guaranteed.
