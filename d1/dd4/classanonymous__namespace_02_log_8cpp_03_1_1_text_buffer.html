Description

template<size_t LineSize, size_t LineCount = 1u>
class anonymous_namespace{Log.cpp}::TextBuffer< LineSize, LineCount >

Provides a fixed-capacity, allocation-free text buffer.

Text is sanitized as it is appended, whitespace is normalized, the pipe character is reserved for field separation, and non-ASCII text is represented with question marks. Multiple fixed-size lines can be accumulated without dynamic allocation, which also makes the buffer suitable for fatal and crash paths.

Template Parameters
LineSizeMaximum bytes available to one line, including its terminator.
LineCountCapacity multiplier; total storage is LineSize * LineCount.
