Description

template<typename T>
class npi::ind::LockedValue< T >::ReadAccess

Provides scoped read-only access to the protected value.

Acquires the internal lock for reading during construction and releases it when destroyed. The access object cannot be copied or moved.

Warning
References and pointers obtained through this object must not be retained after the access object is destroyed.
