npi::ind::EmptyCompleter Class Referencefinal

#include <EmptyCompleter.hpp>

Description

Extends QCompleter to show popup when QLineEdit gains focus or is empty.

Extends the standard QCompleter behavior by providing completion popups in two specific cases not handled by Qt's normal completion mechanism:

  • When QLineEdit gains focus, and
  • When Backspace/Delete is used and QLineEdit text is empty.

Focus caused by a popup closing or by application-window activation is ignored to prevent the completion popup from immediately reopening during normal popup dismissal or window focus changes.

The additional behavior is applied only when the completer's associated widget is a QLineEdit. Standard QCompleter event handling is otherwise preserved.

void npi::ind::EmptyCompleter::showCompletion_ ( )
inlineprivate

Updates the completion prefix and displays the completion popup.

Uses the current text of the associated QLineEdit as the completion prefix. An empty string is therefore a valid prefix and allows the completer to display all available completions. No action is performed if the associated widget is not a QLineEdit or if the line edit does not currently have focus.
