Description

Implements the application GUI style, theme handling and widget customization.

GuiStyle extends Qt's Fusion style through QProxyStyle, providing custom widget initialization, font-based sizing, control drawing and event handling. It implements the dynamic-property behavior declared in Gui.h, including theme-dependent icons, grouped controls and embedded item-view widgets.

Custom drawing includes control backgrounds and indicators, completion-popup text and multi-level QTableWidget headers. Cases not customized or explicitly suppressed are delegated to the base style.

The implementation maintains dark and light theme resources, applies the selected theme and observes Windows application-theme changes when following the system setting. Native Windows title-bar colors are updated separately from each window's palette.

Internal helpers construct drawing resources, render specialized content, resolve dynamic icons, calculate control dimensions and configure widget hierarchies. Bundled fonts are registered before GuiStyle is constructed.

Application-style initialization is scheduled through Qt's startup hook and deferred until events are processed. Public theme-query and configuration functions can also initialize the style on demand after QApplication construction. The standalone text-color helper does not initialize the style.

Public API contracts and property usage requirements are documented in Gui.h.
