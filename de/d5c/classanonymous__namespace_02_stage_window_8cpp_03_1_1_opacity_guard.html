anonymous_namespace{StageWindow.cpp}::OpacityGuard Class Reference

Description

Helper for StageWindow class. A RAII guard that restores a widget's window opacity on scope exit.

For use when the target widget's opacity is set to 0.0 before an animation is fully wired. If control leaves the scope early (exception or early return) and the guard is still active, it restores the widget to full opacity (1.0) in the destructor. After the animation has been started and its own finished-handler will handle restoration, call release_() to disable the guard.

Note
The guard holds a QPointer to avoid dereferencing a deleted widget. If the widget is destroyed before scope exit, no action is taken.
Warning
Construct and use from the GUI thread only. The opacity change affects GUI state.
