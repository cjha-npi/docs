anonymous_namespace{Log.cpp}::control Namespace Reference

Description

Implements validation, persistence, filtering, and configuration changes.

Persistent settings are protected by a cross-process lock. Maximum-folder-size cleanup and persistence use separate debounce timers, while temporary mode keeps configuration changes runtime-only.
