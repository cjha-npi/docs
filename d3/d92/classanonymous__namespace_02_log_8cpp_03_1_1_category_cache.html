anonymous_namespace{Log.cpp}::CategoryCache Class Referencefinal

Description

Caches normalized logging-category text.

Cache keys are derived from the pointed-to text rather than pointer identity. Entries are inserted concurrently, published with atomic state transitions, and stored in a fixed text pool. Slot zero represents an unavailable value.
