anonymous_namespace{Log.cpp}::OneLog Struct Reference

Description

Stores one captured log record for asynchronous processing.

The structure contains compact indices into immutable context caches together with timestamps, thread information, sequence information, level, and message text. Its fixed 64-byte layout keeps queue storage predictable.
