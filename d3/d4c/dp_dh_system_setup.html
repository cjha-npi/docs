System Setup

Structure

Drives:

  • C: Windows : Windows drive (min 250 GB)
  • D: Docs : Documents, Doxygen files, settings, config, etc. (min 20 GB)
  • E: Code : Filtered code files from all projects (min 5 GB)
  • F: Work : Main working directory (remaining space, min 200 GB)

Project Folders:

  • Core : Contains final projects, names start with C e.g. C123_UniClamp
  • Demo : Contains projects demonstrating one or more modules, names start with D e.g. D42_Log
  • Eval : Contains evaluation projects for module development, names start with E e.g. E42_LogTest
  • Form : Contains independent *.ui Qt form file projects, names start with F e.g. F24_LogUI
  • Gear : Contains projects purely made to test/work with hardware, names start with G e.g. G21_MCUConnection
  • Test : Contains small projects just made for testing, names start with T e.g. T78_WinMutex

Other Folders:

  • Solo : Contains independent files, can have any extension.
  • Doxy : Doxygen output.
  • Misc : Miscellaneous files/folders.
  • Temp : Temporary file/folders/projects.

Change File Explorer Font

I prefer file explorer to have fixed width font, this helps in recognizing different and related folders and files. To do this install Windhawk then install Explorer Font Changer mod. Go to the Settings tab for this mod and change the font. Keep Glow text disabled.
