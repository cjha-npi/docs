Description

template<typename T>
class npi::ind::LockedValue< T >

Stores a value protected by a QReadWriteLock.

LockedValue supports three access styles:

  • Copy-based operations through read_() and write_().
  • Function-based operations through readWith_() and writeWith_().
  • Scoped reference access through readAccess_() and writeAccess_().

Snapshot operations hold the lock only while copying or assigning the value. Scoped access objects retain the corresponding lock until the access object is destroyed.

Individual members can be read or written through pointers to data members:

const QString directory = config.read_(&Config::directory_);
config.write_(&Config::maxFolderMb_, 512u);

Multiple related operations can be performed under one lock:

auto config = lockedConfig.writeAccess_();
config->directory_ = newDirectory;
config->maxFolderMb_ = 512u;
Template Parameters
TNon-const, non-volatile, non-array object type to protect.
Warning
The object must outlive all ReadAccess and WriteAccess objects created from it.
Do not call another locking function on the same LockedValue while already holding one of its scoped access objects.
