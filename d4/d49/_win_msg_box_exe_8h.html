WinMsgBoxExe.h File Reference
#include <QStringView>

Description

Declares Windows helper-process message box functions.

These functions launch npiMsgBox.exe to show native Windows message boxes from a separate process. This allows the caller to continue without blocking on MessageBoxW().

The information and warning functions return after launching the helper process. The stop functions launch the helper process and then terminate the current process.

The message text is sanitized by the implementation before it is passed to the helper executable through the command line.
