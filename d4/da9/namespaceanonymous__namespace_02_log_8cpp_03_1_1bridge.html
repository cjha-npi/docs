anonymous_namespace{Log.cpp}::bridge Namespace Reference

Description

Manages the external helper process used for important logs.

The helper receives formatted records through an anonymous pipe and writes them to the primary or backup important-log file. Normal writes are serialized while fatal and crash paths use bounded best-effort coordination.
