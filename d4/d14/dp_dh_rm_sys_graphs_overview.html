Overview

Introduction

CJ_SysGraphs is a Rainmeter skin that displays CPU and RAM activity inside the empty area of a horizontal Windows taskbar. It shows a CPU usage histogram, an optional RAM usage line, and one bar for each logical CPU processor/thread.

The skin uses CJ_SysGraphs.dll to detect the usable taskbar area between the taskbar icons and the system tray. Based on this area, the skin automatically calculates its position, width, graph size, CPU bar width, and spacing.

Per-core CPU bar sections are generated by CJ_SysGraphs_GenCpuBars.lua and written to CJ_SysGraphs_CpuBars.inc. This allows the skin to adapt to the logical processor count of the current system without manually writing one section per CPU core.

The skin also supports hover, double-click, and mouse-scroll interactions for showing details, changing the skin update rate, adjusting the preferred CPU bar width, and changing the CPU tick averaging window.

One of the most important features of this skin is the ability to change the Skin Update Rate easily. This allows the skin to be slowed down when needed, reducing its CPU usage. This is especially useful during CPU-sensitive programming or performance testing.

Requirements

  1. Windows 10 or Windows 11
  2. Rainmeter v4.5 or newer
  3. CJ_SysGraphs.dll plugin

To build the plugin DLL CJ_SysGraphs.dll from the source file CJ_SysGraphs.cpp, the x64 Native Tools Command Prompt for VS 2022 is required. See Build Plugin DLL below.

Build Plugin DLL

  1. Create the CJ_SysGraphs.cpp file and paste the contents from DLL Plugin Source into it.
  2. Open
    x64 Native Tools Command Prompt for VS 2022
    To generate x64 DLL for x64 Rainmeter application. If the Rainmeter is x86 then use a different Command Prompt.
  3. Navigate to the folder containing CJ_SysGraphs.cpp.
    • Use the drive letter only to change drives, for example: D:
    • Then use cd to go to the required folder.
    • Alternatively, use cd /d D:\SomeFolder to change the drive and folder in one step.
    • If the path contains spaces, use double quotes, for example: cd /d "D:\My Folder\Sub Folder"
  4. Run
    cl /std:c++20 /EHsc /O2 /LD CJ_SysGraphs.cpp /link User32.lib Ole32.lib UIAutomationCore.lib /out:CJ_SysGraphs.dll
    • This will generate:
      • CJ_SysGraphs.dll
      • CJ_SysGraphs.obj
      • CJ_SysGraphs.exp
      • CJ_SysGraphs.lib
    • Only CJ_SysGraphs.dll is required by Rainmeter. The other generated files can be safely deleted.
  5. Copy CJ_SysGraphs.dll to Rainmeter's Plugins folder. Create the folder if it does not exist:
    C:\Users\UserName\AppData\Roaming\Rainmeter\Plugins

Installation

Note
The CJ_SysGraphs.dll is not signed, so as long as it is copied locally (e.g. using USB drive) it will work on another computer, howver, as soon as it is downloaded from the internet Windows/Anti-Virus will might complain but its authenticity and flag it.
  1. Make sure the plugin DLL CJ_SysGraphs.dll is placed in the Rainmeter Plugins folder. See Build Plugin DLL to build it locally.
  2. Inside C:\Users\UserName\Documents\Rainmeter\Skins, create the parent folder for this skin. The preferred folder name is CJ_SysGraphs. Inside this folder create the rest of the files below.
  3. Create CJ_SysGraphs_GenCpuBars.lua and paste the contents of CPU Bar Generator into it.
  4. Create CJ_SysGraphs.ini and paste the contents of Rainmeter Skin File into it.
  5. Create these two .inc files. They can be created automatically on demand, but Rainmeter logs an include-file error if they do not already exist.
    • CJ_SysGraphs_CpuBars.inc with contents:
      ; ============================================================================
      ; File: CJ_SysGraphs_CpuBars.inc
      ; Generated/Edited automatically by CJ_SysGraphs_GenCpuBars.lua.
      ; --- DO NOT EDIT MANUALLY! ---
      ; ============================================================================
    • CJ_SysGraphs_Stored.inc with contents:
      ; ============================================================================
      ; File: CJ_SysGraphs_Stored.inc
      ; Stored values are written in this file by the Rainmeter Skin.
      ; --- DO NOT EDIT MANUALLY! ---
      ; ============================================================================
  6. Refresh Rainmeter and load the CJ_SysGraphs skin.

Rainmeter Settings

The Coordinates and Position Rainmeter settings are managed automatically by the skin, the skin restores these to correct values if changed.

Below are the required settings:

  • On Hover : Do nothing (other hover modes can interfere with skin interactions).
  • Click through : Unchecked (otherwise mouse interaction will not work).

Basic Interactions

  1. Graph Area (CPU Histogram + RAM Line):
    • Hover : Temporarily show or hide graph details.
    • Double-Click : Permanently toggle graph details.
    • Graph Text (CPU & RAM Percentages):
      • Hover : Show the current Skin Update rate and dependent Text Update rate.
      • Scroll : Change the Skin Update rate and dependent Text Update rate.
        • The new value is previewed in the tooltip.
        • The change is applied when the mouse leaves the graph text.
  2. CPU Bar Area:
    • Hover : Temporarily show or hide CPU core bar details.
    • Double-Click : Permanently toggle CPU core bar details.
    • CPU Core Label:
      • Hover : Show the current Tick Window Duration.
      • Scroll : Change the Tick Window Duration. The change takes effect immediately.
    • Scroll (below CPU Core Labels) : Change the CPU core bar preferred width.

Saved settings are written to CJ_SysGraphs_Stored.inc and restored the next time the skin is loaded.

Customization

Most user-editable settings are defined near the top of CJ_SysGraphs.ini in the [Variables] section. Values below the DO NOT EDIT MANUALLY BEYOND THIS POINT marker are internal runtime values and should not be changed manually.

The main customizable values are:

  1. Font Settings

    • FontFamilyName : Text font family. Fixed-width font preferred. Default Consolas.
    • FontPointSize : Text point size. Range 5 - 64 Default 10

    These control the font used by graph text and CPU core labels.

  2. Spacing and Layout
    • Gap : Controls spacing between meters. Even numbers only. Range 4 - 64 Default 6.
    • TextMargin : Controls the graph text margin on the left and top. Range 0 - 64 Default 3.
    • GraphMaxWidth : Limits the maximum CPU/RAM graph width. Range 200 - 6400 Default 1200.
    • BarPreferredWidth : Controls the preferred width of each CPU core bar. The actual bar width may be reduced automatically when there is not enough taskbar space. Range 4 - 200 Default 12.

  3. CPU Thresholds

    • CPUMidBeg
    • CPUMaxBeg

    These values define when the CPU histogram changes color. Values are in percentages.

    • Below CPUMidBeg: low CPU load color
    • From CPUMidBeg to below CPUMaxBeg: mid CPU load color
    • From CPUMaxBeg to 100: max CPU load color

  4. Theme Colors

    Theme-dependent colors are defined in matching Dark_ and Lite_ pairs, for example:

    Dark_CPUMax=120,0,0,255
    Lite_CPUMax=210,0,0,255

    The skin automatically selects Dark_ or Lite_ colors based on the Windows app theme setting. The color values use the R,G,B,A format, where:

    • R, G, and B are color channels from 0 to 255
    • A is opacity from 0 to 255:
      • 0 = fully transparent
      • 255 = fully opaque

  5. Saved Runtime Settings Some settings are changed through mouse interactions instead of direct editing:

    • Graph details visibility
    • CPU bar details visibility
    • Skin update rate
    • Preferred CPU core bar width
    • CPU tick window duration

    These values are written to CJ_SysGraphs_Stored.inc and restored when the skin is loaded again.

Limitations

  1. Horizontal taskbar only

    The skin is designed for taskbars placed at the top or bottom of the screen. If the taskbar is placed on the left or right side, the skin shows a warning and unloads itself.

  2. Depends on usable empty taskbar space

    The skin uses the empty area between the taskbar icons and the system tray. If there is not enough space, the CPU core bars may be reduced in width or hidden. If the graph cannot fit its minimum required width, the skin will not show the graph area.

  3. Requires the plugin DLL

    Taskbar position and size detection depends on CJ_SysGraphs.dll. If the plugin is missing, installed in the wrong folder, or built for the wrong architecture, the skin cannot calculate the taskbar area correctly.

  4. Designed for the standard Windows taskbar

    The skin is intended for the normal Windows 10/11 taskbar. Third-party taskbar replacements, heavily modified taskbars, or unusual shell customizations may give incorrect taskbar geometry.

  5. Not compatible with Taskbar Widgets

    Enabling Taskbar Widgets adds a widget icon on the right end of the taskbar, just before the system tray. This reduces the available width obtained from CJ_SysGraphs.dll to almost zero, preventing the display of graph and CPU bars.

  6. Generated CPU bar file should not be edited manually

    CJ_SysGraphs_CpuBars.inc is generated by CJ_SysGraphs_GenCpuBars.lua. Manual changes to this file can be overwritten the next time the generated output changes.

  7. CPU core count is handled at skin load/refresh

    Per-core CPU bar sections are generated when the skin loads or refreshes. This is sufficient for normal systems because the logical processor count does not usually change while Rainmeter is running.

Troubleshooting

Restore Defaults: Open CJ_SysGraphs_Stored.inc and delete everything under [Variables] section and refresh the skin. This will remove all stored values and the skin will start with default values.
