CJ_SysGraphs.ini File

Introduction

CJ_SysGraphs.ini is the main Rainmeter skin file for CJ_SysGraphs. It defines the skin metadata, update behavior, variables, layout calculations, plugin measures, CPU/RAM meters, generated include usage, theme handling, position locking, topmost behavior, and double-click text toggle logic.

The skin displays CPU and RAM usage inside the empty horizontal area of the Windows taskbar on the main display. It calculates the available taskbar space between the last taskbar icon and the system tray, then adjusts its own width, position, CPU bars, and histograms to fit that space.

Compact

CJ_SysGraphs.ini is the main Rainmeter skin file. It defines the skin metadata, variables, measures, meters, layout calculations, theme handling, state restore/save logic, positioning behavior, and user interaction.

It uses CJ_SysGraphs.dll to read the available horizontal taskbar space, then positions and resizes the skin inside that area. It displays per-logical-CPU bars, an overall CPU histogram, a RAM histogram, and optional text labels. The CPU bars are loaded from the generated include file CJ_SysGraphs_CpuBars.inc, while persistent values such as ShowText are restored from CJ_SysGraphs_Stored.inc.

The file also handles Windows light/dark theme detection, threshold-based graph colors, automatic movement back to the calculated taskbar position, topmost-state restoration, and double-click text toggling.

Plugin-Based Taskbar Layout

The skin uses CJ_SysGraphs.dll to get taskbar layout information. The plugin provides five values:

Measure Plugin value Meaning
MeasureDisp Disp Indicates whether the taskbar is horizontal or vertical.
MeasureBegX BegX X-position where the empty taskbar area begins.
MeasureEndX EndX X-position where the empty taskbar area ends.
MeasureBegY BegY Top Y-position of the taskbar.
MeasureEndY EndY Bottom Y-position of the taskbar.

If MeasureDisp returns 0, the skin treats the taskbar as vertical. Since the skin is designed only for top/bottom taskbars, it shows a warning message and unloads itself.

Layout Calculation

The skin calculates its layout dynamically from the available taskbar area.

The main calculated values are:

Measure Purpose
AvailableWidth Total empty horizontal taskbar space available to the skin.
BarPreferredWidthCalc Checks whether preferred CPU bar width can fit.
BarMinWidthCalc Checks whether minimum CPU bar width can fit.
BarWidth Final per-CPU bar width.
HistWidthRaw Raw width available to each histogram.
HistWidth Final visible histogram width after clamping.
SkinWidth Final skin width.
XCoord Final skin X-position.
YCoord Final skin Y-position.
SkinHeight Final skin height.

The layout tries to keep all visual parts visible. If space is limited, it first reduces CPU bar width. If there is still not enough space, it hides CPU bars and/or histograms by setting their calculated widths to 0.

Generated CPU Bars

The per-logical-CPU bar sections are not written manually in the main file. They are generated by:

CJ_SysGraphs_GenCpuBars.lua

The generated content is written to:

CJ_SysGraphs_CpuBars.inc

This include file contains one CPU measure, one CPU bar meter, and one CPU text meter for each logical CPU thread.

The main skin runs the Lua script through the GenerateCpuBars script measure. The script checks whether the generated output has changed before writing the include file. This prevents unnecessary skin refreshes.

The include file must exist before the first skin load to avoid a Rainmeter include-file warning. After the first successful run, the Lua script can create or update it automatically.

CPU and RAM Histograms

The skin shows two overall histograms:

Histogram Meaning
CPU histogram Overall CPU usage from MeasureCPU.
RAM histogram Physical memory usage calculated from used RAM and total RAM.

Each histogram is built from three overlapping histogram meters:

Meter type Usage range
Minimum meter Usage below the lower threshold.
Medium meter Usage between lower and upper thresholds.
Maximum meter Usage above the upper threshold.

Only one of the three related measures has a non-zero value at a time, so the three meters appear as one histogram whose color changes based on the current usage value.

Histogram History Preservation

Rainmeter histogram meters lose their stored history when their width changes. This is a problem for this skin because the available taskbar area can change when taskbar icons appear or disappear.

To avoid history loss, the actual histogram meters keep a fixed backing width defined by HistWidthMax. The visible width is controlled by a container meter whose width is set to HistWidth.

The container clips the histogram, so the visible graph can shrink or grow without resizing the actual histogram meter. This preserves the graph history during layout changes.

Theme and Colors

The skin reads the Windows app theme setting from the registry using MeasureTheme.

It switches between two color sets:

Theme Variables used
Light theme LightBgTxt, LightBgMax, LightBgMid, LightBgMin
Dark theme DarkBgTxt, DarkBgMax, DarkBgMid, DarkBgMin

The active color variables are:

Variable Purpose
TxtColor Text color.
MaxColor High usage color.
MidColor Medium usage color.
MinColor Low usage color.

The CPU bars and histograms use these active variables so the skin follows the current Windows theme.

Stored State

The skin stores user-selected text visibility in:

CJ_SysGraphs_Stored.inc

The stored value is:

Variable Meaning
ShowText=0 Hide CPU/RAM text labels.
ShowText=1 Show CPU/RAM text labels.

The stored include is loaded after the default variable values, so the saved value overrides the default ShowText=0.

Double-Click Text Toggle

The final meter in the file is ClickBackground. It is an almost-transparent full-skin meter used to detect double-clicks.

Rainmeter mouse actions must be attached to a meter, so this meter covers the full skin area and is drawn above all other meters.

On double-click, it:

  1. Updates MeasureToggleShowText.
  2. Writes the new ShowText value to CJ_SysGraphs_Stored.inc.
  3. Updates the active ShowText variable.
  4. Updates the TextMeter group.
  5. Redraws the skin.

The meter uses alpha value 1 instead of full transparency because a completely transparent meter may not reliably receive mouse input.

Position and Topmost Enforcement

The skin continuously checks whether its current position matches the calculated taskbar position.

If the skin is moved accidentally or the taskbar layout changes, MeasureMoveTrigger moves it back to [XCoord] [YCoord].

The skin also checks its Z-position. If it is no longer topmost, MeasureZPosTrigger restores ZPos=2.

These checks use IfConditionMode=1 so the corrective actions can run repeatedly while the wrong state remains true. This is important when the skin is being dragged or when Rainmeter does not immediately settle into the required position.

; the current HistWidth. The container clips the left side of the histogram, while
; the newest values remain visible on the right.
;
; Value-based colors:
; Rainmeter histograms use one color per meter. To show different colors for low,
; medium, and high values, each visible graph is built from three overlapping
; histograms:
; - Min histogram:
; Receives the value only below the minimum threshold.
; - Mid histogram:
; Receives the value only between the minimum and maximum thresholds.
; - Max histogram:
; Receives the value only above the maximum threshold.
; At any time, only one of the three derived measures has a non-zero value, so the
; stacked meters look like one histogram whose color changes with the current
; value.
