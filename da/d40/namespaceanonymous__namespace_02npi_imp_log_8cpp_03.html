anonymous_namespace{npiImpLog.cpp} Namespace Reference

Description

Helper functions for npiImpLog.exe path handling and file opening.

These helpers intentionally implement only basic robustness:

  • convert Qt-style forward slashes to Windows backslashes,
  • reject directory-style file paths,
  • require drive-letter absolute paths,
  • create missing parent directories,
  • open files in append mode.
