Description

Color selection widget and modal dialog.

Declares npi::wid::ColorPicker for editing colors using RGB, HSL or HSV channels, with optional alpha editing and a color preview.

Channel ranges and editing locks are configured separately from the widget's presentation, including control visibility, layout orientation, background and font options.

The widget can be embedded in a layout or used through GetColor_() to select a color in a modal dialog with a fixed presentation.
