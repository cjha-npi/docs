1/**
2 * \file ColorPicker.h
3 * \brief Color selection widget and modal dialog.
4 *
5 * \details Declares npi::wid::ColorPicker for editing colors using RGB,
6 * HSL or HSV channels, with optional alpha editing and a color preview.
7 *
8 * Channel ranges and editing locks are configured separately from the
9 * widget's presentation, including control visibility, layout orientation,
10 * background and font options.
11 *
12 * The widget can be embedded in a layout or used through GetColor_()
13 * to select a color in a modal dialog with a fixed presentation.
14 */

33 /**
34 * \class ColorPicker
35 * \brief Widget for editing and previewing a color.
36 *
37 * \details Supports RGB, HSL and HSV editing with a shared alpha channel.
38 * Config controls the selected color model, channel ranges and editing locks.
39 * Design controls the embedded widget's appearance and layout.
40 *
41 * Only the selected model's channel limits and the alpha limits apply to
42 * the current color. Editing locks prevent user changes but do not prevent
43 * programmatic updates.
44 *
45 * User edits emit colorChanged_() when the color changes.Programmatic setters
46 * do not emit the signal unless explicitly requested.
47 *
48 * Use GetColor_() for modal color selection. The dialog uses Config but
49 * provides its own fixed presentation rather than accepting Design.
50 */

63 /// \brief Identifies a configurable color or alpha channel.

78 /// \brief Value limits and editing lock for one channel.
79 /// \details When applied, limits are clamped to the channel's supported range:
80 /// 0-359 for hue, otherwise 0-255. If the minimum exceeds the maximum,
81 /// the minimum is reduced to the maximum.

83 /// \note Locking disables user editing but does not prevent programmatic changes.

90 /// \brief Color model, channel limits and editing locks.
91 /// \details Stores independent settings for RGB, HSL and HSV.
92 /// Only the selected model's channel limits apply to the current color.
93 /// Alpha limits apply regardless of the selected model or control visibility.

95 /// \note Editing locks prevent user changes, not programmatic updates.
96 /// Locking a channel does not automatically lock color-model selection.

141 /// \brief Opens a modal dialog for selecting a color.
