1/**
2 * \file Log.h
3 * \brief Declares runtime configuration and console controls for the logging system.
4 *
5 * \details
6 * The logging system installs a Qt message handler during application startup and
7 * processes non-fatal messages using dedicated file and display workers. Non-fatal
8 * records are written to `*.log` files. Configured warnings and all critical records
9 * are additionally forwarded to an `*.imp.log` file through a helper process.
10 * Fatal records bypass the asynchronous normal-file queue and use the synchronous
11 * important-log path.
12 *
13 * This file provides functions for querying and changing the log directory, folder
14 * size limit, output fields, category filter rules, display-level settings, warning
15 * importance, console colors, display muting, and temporary console state.
16 *
17 * Runtime configuration changes are persisted unless temporary mode is enabled.
18 * Display muting and temporary console state are always runtime-only.
19 */

40 * for file output, display output, field layouts, category filters, important-log
41 * forwarding, and console management.

44 * are intended to be called from the GUI thread. State-query functions are
