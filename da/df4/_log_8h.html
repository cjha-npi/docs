Description

Declares runtime configuration and console controls for the logging system.

The logging system installs a Qt message handler during application startup and processes non-fatal messages using dedicated file and display workers. Non-fatal records are written to *.log files. Configured warnings and all critical records are additionally forwarded to an *.imp.log file through a helper process. Fatal records bypass the asynchronous normal-file queue and use the synchronous important-log path.

This file provides functions for querying and changing the log directory, folder size limit, output fields, category filter rules, display-level settings, warning importance, console colors, display muting, and temporary console state.

Runtime configuration changes are persisted unless temporary mode is enabled. Display muting and temporary console state are always runtime-only.
