anonymous_namespace{Log.cpp}::FunctionCache Class Referencefinal

Description

Caches normalized function names from Qt message contexts.

Return types and parameter lists are removed while operator names, qualifiers, scopes, and template arguments are retained on a best-effort basis. Entries are stored in a fixed pool and referenced by compact 16-bit slots.
