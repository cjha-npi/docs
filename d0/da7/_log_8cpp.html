Description

Implements the asynchronous application logging system.

This translation unit installs the Qt message handler, captures and normalizes message context, formats normal and important log records, manages file and display worker threads, controls permanent and temporary consoles, persists runtime configuration, performs log-directory cleanup, and installs fatal and crash handlers. Important records are forwarded to the external npiImpLog helper process so that critical information can still be written during fatal failures and abnormal termination.

The implementation is Windows-specific and intentionally keeps its central state alive until process termination so that logging remains available during static destruction and emergency handling.

Note
This implementation is intentionally documented selectively. Because the file is large, comments focus on architecture, ownership, synchronization, invariants, failure handling, and other non-obvious design decisions. Straightforward code is generally left uncommented to avoid obscuring the implementation with comments that merely repeat what the code already expresses.
