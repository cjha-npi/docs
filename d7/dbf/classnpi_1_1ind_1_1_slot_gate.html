npi::ind::SlotGate Class Referencefinal

#include <SlotGate.hpp>

Description

Controls scoped suppression of reentrant or unwanted slot handling.

SlotGate maintains an internal blocking count. Each active Blocker increments this count when created and decrements it when destroyed. The gate remains blocked while at least one associated Blocker exists.

block_() always creates an additional Blocker and therefore supports nested blocking scopes. tryEnter_() creates a Blocker only when the gate is currently unblocked, allowing only the first or outermost invocation to proceed.

A SlotGate must outlive every Blocker created from it. A typical use is to store SlotGate as a member of a GUI class and use Blocker objects only as local variables inside that class's member functions.

This class is not thread-safe and is intended for single-threaded use, particularly on the Qt GUI thread.
