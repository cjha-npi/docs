Branch Attributes

Each branch has these branch-specific attributes:

  1. Parent Folder
  2. Page ID Prefix
  3. Contents ID Prefix
  4. Top-Level Contents ID
  5. Images Folder

Project Independent Branches

Dev Hub Branch

This branch is common to all projects and contains documentation pages related to the documentation setup, generated output customization, helper pages, known issues, and other development-support information.

Attribute Value
Parent Folder _dev
Page ID Prefix dp_dh_
Contents ID Prefix dp_dh_dir_
Top-Level Contents ID dp_dh_dir_dev_hub
Images Folder _dev/_images
Precondition
To include the Dev Hub branch in the Doxygen output add the _dev folder to Doxyfile INPUT tag and the _dev/_images folder to Doxyfile IMAGE_PATH tag

Project Dependent Branches

Dependencies Branch

This branch is project-dependent and contains documentation pages for external tools, libraries, assets, and other resources that the project depends on, but that are not part of the core project codebase and are therefore not documented through the project source files alone (.h, .cpp, etc.).

Attribute Value
Parent Folder <project-root>/_dependencies
Page ID Prefix dp_dep_
Contents ID Prefix dp_dep_dir_
Top-Level Contents ID dp_dep_dir_dependencies
Images Folder <project-root>/_images (shared with project)

Architecture Branch

This branch is project-dependent and contains documentation pages that explain important design decisions, internal structure, major systems, and why specific parts are implemented the way they are. In other words, it provides deeper insight into the architecture of the project.

Attribute Value
Parent Folder <project-root>/_architecture
Page ID Prefix dp_arch_
Contents ID Prefix dp_arch_dir_
Top-Level Contents ID dp_arch_dir_architecture
Images Folder <project-root>/_images (shared with project)

Rest of the document

  • Project Independent: These branches are same for all projects.
    1. Dev Hub: This branch is the developer area and documents development work, project conventions, IDE settings, documentation generation settings, etc., along with their related code files.
  • Project Dependent: These branches can differ between projects.
    1. Dependencies: Contains documentation for all project dependencies that are not part of the core project codebase and are therefore not documented through the project source files alone (.h, .cpp, etc.). For example external tools, helper executables, etc.
    2. Architecture: Contains documentation which provides a coherent and deeper insight into the architecture of the project, detailing specific important parts of the project in a single place. For example, providing a detailed understanding of how and why the logging structure is the way it is and how to use it efficiently.

Branch Rules

  • Required:
    1. Page ID Prefix: All Markdown page ID should start with this prefix.
      • Dev Hub : dp_dh_
      • Dependencies : dp_dep_
      • Architecture : dp_arch_
    2. Top-Level Contents Page: This is the starting point to look for child pages.
      • Dev Hub : dp_dh_dir_dev_hub
      • Dependencies : dp_dep_dir_dependencies
      • Architecture : dp_arch_dir_architecture

Branch rules are divided into 2 categories: Required and Recommended:

  • Parent Folder:
  1. All files and folder should be inside one parent folder.
    • For Dev Hub branch the suggested parent folder name is _dev (this folder should be added to the INPUT tag in Doxyfile).
    • For Dependencies branch the parent folder name is _dependencies and should be placed inside the project folder.
    • For Architecture branch the parent folder name is _architecture and should be placed inside the project folder.
  2. Image files (.png, .jpg, etc.) for use in any of these branches
    • For Dev Hub branch images are placed inside _dev/_images
  1. Only Markdown (.md) and image (.png, .jpg, etc.) files are allowed.
    • For Dev Hub branch image files are placed inside E:/Doxy/_dev/_images.

Special Branches

The Dev Hub allows integration of special branches into the generated Doxygen output. These special branches enhance the structure of the code and provide additional details which otherwise would not have a place to be put into.

Common Rules & Guidelines

Rules: {#dp_dh_dev_hub_overview__special_branches__rules}

  1. All files and folder should be inside one parent folder.
  2. For File/Folder names and Page/Section ID only a-z0-9_ is allowed.
  3. Every Markdown Page ID must start with dp_.
  4. The title of the page is placed next to the Page ID.
  5. A branch/sub-branch is created using a special Markdown page:
    • The Page ID must start with dp_dir_.
    • Contains only single Page ID (with title) and a list of Sub-Page IDs.

REQUIRED
Dev Hub Overview > Special Branches > Rules and Guidelines
