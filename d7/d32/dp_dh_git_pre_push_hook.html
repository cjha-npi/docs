Git Pre-Push Hook

A Git pre-push hook configured using global core.hooksPath to copy code files from a Git repository on F: drive to a predefined target on E: drive.

Details

  • Executes before Git Push.
  • Never blocks i.e. never prevents a Git Push action.
  • Only works for a repository:
    • Under F:\Core\, F:\Demo\ and F:\Eval\.
    • Root containing a *.sln or *.slnx file.
  • Target structure: F:\Eval\SolA > E:\Eval\SolA\_git\<branch name>
  • Uses Robocopy and copies only:
    • Code files: *.h, *.hpp, *.c, and *.cpp
    • Image files: *.png, *.svg, *.jpg, and *.jpeg
    • Font files: *.ttf and *.otf
    • Other files: *.ui, *.qrc, *.md, *.ico, *.rc, and *.ini
  • Deletes empty destination folders.
  • Provides logs.
    • If log exceeds 20 KB, it is rotated to pre-push.log.old
Note
This and Backup Solution Code on Save uses the same basic copying filter rules for Robocopy, so a change in one would mean that the other should be changed similarly.

Setup

Install:

  • Create folder
    D:\ToolBox\Git\Pre_Push_Hook\
  • Place pre-push files in that folder. Make sure that pre-push file has:
    • No extension
    • LF line endings
  • Configure Git to use the global hooks folder (any shell)
    git config --global core.hooksPath "D:/ToolBox/Git/Pre_Push_Hook"
  • Mark the hook executable (Git Bash/MSYS)
    chmod +x /d/ToolBox/Git/Pre_Push_Hook/pre-push

Verify:

  • Check configured hooks path (any shell)
    git config --global --get core.hooksPath

Remove:

  • Disable global hooks path
    git config --global --unset core.hooksPath

Filename:

Contents:

#!/bin/sh
# ------------------------------------------------------------
# Shebang:
# - `#!/bin/sh` selects the interpreter for this hook.
# - In Git for Windows, hooks are executed via an sh-compatible shell.
# - Keeping the shebang improves reliability when the push is triggered
# from non-shell tools (for example Visual Studio).
# ------------------------------------------------------------
# ------------------------------------------------------------
# Purpose:
# Before each Git push, create or update a filtered snapshot of
# the currently checked-out branch.
#
# Source requirements:
# - Repository must be under:
# F:\Core\
# F:\Demo\
# F:\Eval\
# - Repository root must contain a *.sln or *.slnx file.
#
# Target structure:
# F:\Eval\MySolution
# ->
# E:\Eval\MySolution\_git<branch>
#
# The snapshot contains the current filtered working-directory state,
# including matching uncommitted files.
#
# Non-blocking behavior:
# - This hook never blocks a push: it always exits with code 0.
# - Robocopy failures are logged but do not stop the push.
#
# Files copied:
# *.h *.hpp *.c *.cpp *.ui *.qrc *.md *.png *.ico
# *.svg *.jpg *.jpeg *.ttf *.otf *.rc *.ini
#
# Logging:
# - D:\ToolBox\Git\Pre_Push_Hook\pre-push.log (next to this script).
# - Log rotation: if log exceeds 20 KB, it is rotated to pre-push.log.old.
# ------------------------------------------------------------
# ------------------------------------------------------------
# - Installation:
# - Create folder:
# D:\ToolBox\Git\Pre_Push_Hook\
# - Place files in that folder:
# pre-push (this file; no extension; LF line endings)
# - Configure Git to use the global hooks folder (any shell):
# git config --global core.hooksPath "D:/ToolBox/Git/Pre_Push_Hook"
# - Mark the hook executable (Git Bash/MSYS):
# chmod +x /d/ToolBox/Git/Pre_Push_Hook/pre-push
#
# - Verification:
# - Check configured hooks path:
# git config --global --get core.hooksPath
#
# - Removal:
# - Disable global hooks path:
# git config --global --unset core.hooksPath
# ------------------------------------------------------------
# ------------------------------------------------------------
# Path conventions:
# - For shell operations and redirection in `sh`, use MSYS/Unix-style
# paths (e.g. /f/Eval/SolA or /c/git-hooks).
# - For Windows tools (PowerShell, robocopy), use Windows drive-letter
# paths (e.g. F:\Eval\SolA). Some tools accept forward slashes, but
# backslashes are the safest/canonical form.
#
# Naming:
# - `*_UNIX`: MSYS/Unix-style paths (e.g. /f/Eval/SolA)
# - `*_WIN_ANY_SLASHES`: Windows drive-letter path where slash style is
# not guaranteed (e.g. F:/Eval/SolA or F:\Eval\SolA)
# - `*_WIN`: Windows drive-letter path normalized to backslashes
# (e.g. F:\Eval\SolA)
# ------------------------------------------------------------
# Require Invocation Through an Actual Hook Path
# ------------------------------------------------------------
case "$0" in
*/*|*\\*) ;; # OK: invoked with a path component
*)
# Unexpected (typically manual invocation via PATH). Skip to avoid
# writing logs in the wrong place and to avoid /PURGE risk.
exit 0 ;;
esac
# Hook and Log Paths
# ------------------------------------------------------------
# Hook directory (MSYS/Unix-style path, suitable for sh file operations)
HOOK_UNIX="$(cd "$(dirname "$0")" 2>/dev/null && pwd)"
if [ -z "$HOOK_UNIX" ]; then
exit 0
fi
# Current log file path (MSYS/Unix-style for sh redirection)
LOG_UNIX="$HOOK_UNIX/pre-push.log"
# Rotated/old log file path (MSYS/Unix-style for sh file operations)
OLD_LOG_UNIX="$HOOK_UNIX/pre-push.log.old"
# Log Rotation: 20 KiB
# ------------------------------------------------------------
# Goal:
# - Prevent the hook log from growing without bound.
#
# Behavior:
# - If `pre-push.log` exists and exceeds 20 KB (20480 bytes):
# 1) delete `pre-push.log.old` if present
# 2) move `pre-push.log` -> `pre-push.log.old`
# - Subsequent writes will create/append to a fresh `pre-push.log`.
if [ -f "$LOG_UNIX" ]; then
size_bytes="$(wc -c <"$LOG_UNIX" 2>/dev/null | tr -d '[:space:]')"
if [ -n "$size_bytes" ] && [ "$size_bytes" -gt 20480 ]; then
[ -f "$OLD_LOG_UNIX" ] && rm -f "$OLD_LOG_UNIX"
mv -f "$LOG_UNIX" "$OLD_LOG_UNIX"
fi
fi
# Timestamp Helper
# ------------------------------------------------------------
# - Uses PowerShell `Get-Date` to get a reliable Windows timestamp with
# milliseconds (yyyy-MM-dd HH:mm:ss.fff).
# - `tr -d '\r'` removes the trailing CR from `powershell.exe` output.
get_timestamp() {
powershell.exe -NoProfile -Command \
"Get-Date -Format 'yyyy-MM-dd HH:mm:ss.fff'" \
2>/dev/null | tr -d '\r'
}
# Non-Blocking Exit Helper
# ------------------------------------------------------------
# Provide a single, consistent way to finish the hook:
# - write a timestamped footer to the log
# - exit with code 0 (success) always (never block the push)
done_and_exit_0() {
END_DT="$(get_timestamp)"
{
echo ""
echo "==================== Pre-Push End: $END_DT ===================="
} >>"$LOG_UNIX" 2>&1
exit 0
}
# Resolve Repository Root
# ------------------------------------------------------------
# Source/repo root
SOURCE_UNIX="$(git rev-parse --show-toplevel 2>/dev/null || printf '')"
# Check repository root
if [ -z "$SOURCE_UNIX" ] || ! cd "$SOURCE_UNIX" 2>/dev/null; then
BEG_DT="$(get_timestamp)"
[ -s "$LOG_UNIX" ] && echo "" >>"$LOG_UNIX"
{
echo "=================== Pre-Push Start: $BEG_DT ==================="
echo ""
echo "ERROR: Unable to determine or enter the Git repository root."
echo "SOURCE_UNIX = $SOURCE_UNIX"
} >>"$LOG_UNIX" 2>&1
done_and_exit_0
fi
# Source directory as Windows path (slash style not guaranteed)
SOURCE_WIN_ANY_SLASHES="$(pwd -W 2>/dev/null || printf '')"
# Normalize to backslashes
SOURCE_WIN="$(printf '%s' "$SOURCE_WIN_ANY_SLASHES" | sed 's,/,\\,g')"
# Check source directory
if [ -z "$SOURCE_WIN" ]; then
BEG_DT="$(get_timestamp)"
[ -s "$LOG_UNIX" ] && echo "" >>"$LOG_UNIX"
{
echo "=================== Pre-Push Start: $BEG_DT ==================="
echo ""
echo "ERROR: Unable to convert the repository root to a Windows path."
} >>"$LOG_UNIX" 2>&1
done_and_exit_0
fi
# Determine Branch Directory
# ------------------------------------------------------------
BRANCH="$(git branch --show-current 2>/dev/null || printf '')"
if [ -z "$BRANCH" ]; then
SHORT_COMMIT="$(git rev-parse --short HEAD 2>/dev/null || printf 'UNKNOWN')"
BRANCH="DETACHED_$SHORT_COMMIT"
fi
# Replace characters unsuitable for a Windows folder name.
BRANCH_DIR="$(
printf '%s' "$BRANCH" |
sed 's,[/\\‍],_,g; s,[:*?"<>|],_,g'
)"
[ -n "$BRANCH_DIR" ] || BRANCH_DIR="UNKNOWN"
# Construct Destination
# ------------------------------------------------------------
TARGET_BASE_WIN="$(
printf '%s' "$SOURCE_WIN" |
sed 's,^[Ff]:\\,E:\\,'
)"
TARGET_WIN="$TARGET_BASE_WIN\\_git\\$BRANCH_DIR"
# Start Log Entry
# ------------------------------------------------------------
BEG_DT="$(get_timestamp)"
[ -s "$LOG_UNIX" ] && echo "" >>"$LOG_UNIX"
{
echo "=================== Pre-Push Start: $BEG_DT ==================="
echo ""
echo "SOURCE = $SOURCE_WIN"
echo "BRANCH = $BRANCH"
echo "TARGET = $TARGET_WIN"
echo ""
echo "Checking conditions..."
} >>"$LOG_UNIX" 2>&1
# Gate 1: Approved Source Roots
# ------------------------------------------------------------
case "$SOURCE_WIN" in
[Ff]:\\‍[Cc][Oo][Rr][Ee]\\*)
;;
[Ff]:\\‍[Dd][Ee][Mm][Oo]\\*)
;;
[Ff]:\\‍[Ee][Vv][Aa][Ll]\\*)
;;
*)
echo "1. Repository under F:\\Core, F:\\Demo, or F:\\Eval: NO (skipping)" \
>>"$LOG_UNIX"
done_and_exit_0
;;
esac
echo "1. Repository under F:\\Core, F:\\Demo, or F:\\Eval: YES" \
>>"$LOG_UNIX"
# Gate 2: Solution File in Repository Root
# ------------------------------------------------------------
SOLUTION_FILE=""
for file in ./*.sln ./*.SLN ./*.slnx ./*.SLNX; do
[ -f "$file" ] || continue
SOLUTION_FILE="$file"
break
done
if [ -z "$SOLUTION_FILE" ]; then
echo "2. Repository root contains .sln/.slnx: NO (skipping)" \
>>"$LOG_UNIX"
done_and_exit_0
fi
echo "2. Repository root contains .sln/.slnx: YES ($SOLUTION_FILE)" \
>>"$LOG_UNIX"
echo "Conditions met. Running Robocopy..." >>"$LOG_UNIX"
# Filtered Branch Snapshot
# ------------------------------------------------------------
set -f
MSYS2_ARG_CONV_EXCL='*' MSYS_NO_PATHCONV=1 \
"/c/Windows/System32/robocopy.exe" \
"$SOURCE_WIN" "$TARGET_WIN" \
"*.h" "*.hpp" "*.c" "*.cpp" "*.ui" "*.qrc" "*.md" "*.png" "*.ico" \
"*.svg" "*.jpg" "*.jpeg" "*.ttf" "*.otf" "*.rc" "*.ini" \
/S /PURGE /R:1 /W:1 /XJ \
/XD ".*" "_git" "x64" "x86" "bin" "obj" "out" "build" \
"_ReSharper.Caches" "GeneratedFiles" "Debug" "Release" \
/XF ".*" "*.sln" "*.slnx" "*.vcxproj" "*.vcxproj.filters" "*.vcxproj.user" \
/NFL /NDL /NJH /NJS /NP \
>>"$LOG_UNIX" 2>&1
rc=$?
set +f
# Remove Empty Destination Directories
# ------------------------------------------------------------
if [ "$rc" -lt 8 ]; then
TARGET_FOR_CLEANUP="$TARGET_WIN" \
powershell.exe -NoProfile -Command '
$root = $env:TARGET_FOR_CLEANUP
if (Test-Path -LiteralPath $root) {
Get-ChildItem -LiteralPath $root -Directory -Recurse -Force |
Sort-Object FullName -Descending |
ForEach-Object {
$item = Get-ChildItem -LiteralPath $_.FullName -Force |
Select-Object -First 1
if ($null -eq $item) {
Remove-Item -LiteralPath $_.FullName -Force
}
}
$rootItem = Get-ChildItem -LiteralPath $root -Force |
Select-Object -First 1
if ($null -eq $rootItem) {
Remove-Item -LiteralPath $root -Force
}
}
' >>"$LOG_UNIX" 2>&1
fi
# Interpret Robocopy Result
# ------------------------------------------------------------
if [ "$rc" -lt 8 ]; then
case "$rc" in
0) message="0: OK - No changes." ;;
1) message="1: OK - Copied files." ;;
2) message="2: OK - Removed destination extras." ;;
3) message="3: OK - Copied files and removed extras." ;;
4) message="4: OK - With mismatches reported." ;;
5) message="5: OK - Copied files with mismatches reported." ;;
6) message="6: OK - Removed extras with mismatches reported." ;;
7) message="7: OK - Copied files and removed extras with mismatches reported." ;;
*) message="$rc: OK - Unexpected informational result." ;;
esac
echo "Robocopy success. $message" >>"$LOG_UNIX"
else
echo "Robocopy failure. Exit code = $rc. Push will continue." \
>>"$LOG_UNIX"
fi
# Write Footer and Exit
# ------------------------------------------------------------
done_and_exit_0
