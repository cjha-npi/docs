npi::gui Namespace Reference

Description

Configuration and control of the application's graphical user interface.

Provides the public interface for querying and controlling the application GUI, including theme selection, theme colors and special widget dynamic properties.

Initialization
GUI initialization is scheduled during application startup and runs when events are first processed, through QApplication::exec() or an explicit QCoreApplication::processEvents() call. Calling any function declared in this namespace also initializes the GUI if initialization is permitted. Initialization requires a fully constructed QApplication and does not occur after application shutdown has begun.

The preferred application startup sequence is to call QCoreApplication::processEvents() immediately after constructing QApplication in main(), before creating widgets. This processes the deferred GUI initialization and any other pending startup events.

Note
  • Use this interface from the GUI thread.
  • Normal use requires a QApplication. Individual functions document their fallback behavior when no application exists or shutdown has begun.
Warning
Do not extend this namespace beyond Gui.h file.

◆ themeAction()

QAction * npi::gui::themeAction ( Theme theme)

Returns the shared checkable action for selecting a theme.

Its exclusive checked state follows theme(), not the effective background. Use QToolButton::setDefaultAction() or add to menus/toolbars; no extra theme-setting connection is needed. All users share the action's properties.

Returns
Theme QAction pointer; nullptr for an invalid theme, absent QApplication or during shutdown.
Warning
The returned QAction* is owned by the GUI style. Do not delete, reparent, regroup or change checkability/checked state. Select themes through setTheme() or QAction::trigger(). See GUI Systems documentation for use inside npi::gui::Props::ButtonGroupBase_.
