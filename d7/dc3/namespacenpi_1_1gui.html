npi::gui Namespace Reference

Description

Runtime configuration and control of the application's graphical user interface.

Provides the public interface for querying and controlling the application GUI, including theme selection, theme colors and special widget properties.

Note
Except for textColor(), the public functions require an existing QApplication instance and initialize and install the application style on demand if needed. textColor() does not require GUI initialization.

QColor npi::gui::textColor ( const QColor & background)

Selects a black or white text color for the specified background.

Uses a weighted RGB brightness heuristic, returning white for darker backgrounds and black for lighter backgrounds. This does not guarantee a particular contrast ratio.

Parameters
backgroundA valid background color. For a translucent background, pass its final composited color.
Returns
White if the weighted brightness is below 128; otherwise black.
Note
The background's alpha component is ignored.
