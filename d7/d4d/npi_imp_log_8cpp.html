Description

Background log writer executable.

Reads bytes from standard input and appends them to a primary log file. If the primary file cannot be opened or created, an optional backup file is used instead. The helper normalizes path separators, creates missing parent directories, and keeps the write loop independent of the main application.

Expected arguments:

  • argv[1]: primary log file path.
  • argv[2]: optional backup log file path.

Return codes:

  • 0: Normal shutdown.
  • 1: Missing or invalid primary path argument.
  • 2: Primary path ends with a slash.
  • 3: Backup path ends with a slash.
  • 4: Missing or invalid standard input handle.
  • 5: Standard input read failed.
  • 6: Failed to open or create both primary and backup files.
  • 7: Failed to open or create primary file, and no backup was provided.
  • 8: File write failed.
  • 9: File write made no progress after repeated attempts.

Program entry point for the background log writer.

Reads all bytes from standard input and appends them to the selected log file. The primary path is tried first. If it cannot be opened or created, the backup path is tried when provided.
