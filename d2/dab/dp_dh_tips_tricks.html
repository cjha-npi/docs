Create ICO Icons Using ImageMagick

Create a multi-size .ico file from a .png or other type of file using ImageMagick. The ImageMagick is an open-source software suite, used for editing and manipulating digital images. To install:

  1. Go to official ImageMagick Download Page
  2. Download the current Q16 (16 bits-per-pixel) x64 DLL .exe installer e.g. ImageMagick-7.1.2-23-Q16-HDRI-x64-dll.exe
  3. Run the installer, during installation, enable these options if shown:
    • Add application directory to your system path
    • Install legacy utilities
  4. Verify: In a Command Prompt magick -version or magick identify -version.

Usage

Make sure the input image:

  • is at least 512x512 with square aspect ratio
  • has transparent background if possible

Use the following command in a command prompt and change input.png and output.ico as required.

magick input.png -define icon:auto-resize=256,128,64,48,32,24,16 output.ico

ImageMagick will resize the original .png into all those sizes and pack them into one .ico file.
