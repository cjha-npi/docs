Description

Implements the npiMsgBox.exe helper process.

This executable shows a native Windows message box from a separate process. It is intended for fire-and-forget messages where the caller should not block.

Expected command line: "full\path\to\npiMsgBox.exe" "Title" "Message" "Severity"

Severity:

  • 0 = information
  • 1 = warning
  • 2 = error / stop

The parent process is responsible for sanitizing command-line arguments before launching this executable.
