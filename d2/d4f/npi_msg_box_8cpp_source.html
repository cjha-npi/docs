5* \details
6* This executable shows a native Windows message box from a separate process.
7* It is intended for fire-and-forget messages where the caller should not block.
8*
9* Expected command line:
10* "full\path\to\npiMsgBox.exe" "Title" "Message" "Severity"

12* Severity:
13* - 0 = information
