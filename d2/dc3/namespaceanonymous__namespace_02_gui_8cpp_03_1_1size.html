Calculates standardized widget and icon dimensions for a font.

Uses the application font with the widget font's configured size, adds space for borders and icon separation, and normally rounds the resulting height up to the next heightQuantum increment. The height is constrained by the normalized minimum and maximum values.

Parameters
widFontFont whose configured pixel or point size is used.
minHeightRequested minimum height; values below 12 are treated as 12.
maxHeightRequested maximum height; values below the normalized minimum are raised to that minimum.
Returns
The calculated widget height, icon size, icon separation and font height.
Precondition
A QApplication instance exists.

◆ sameFontSize()

bool anonymous_namespace{Gui.cpp}::size::sameFontSize ( const QFont & font1,
const QFont & font2 )

Returns whether two fonts use the same configured size.

Pixel sizes are compared when either font is pixel-sized; both fonts must then have the same positive pixel size. Otherwise, their integer point sizes are compared.

Note
A pixel-sized font and a point-sized font are never considered equal. For pixel-sized fonts, pointSize() and pointSizeF() return -1. For point-sized fonts, pixelSize() returns -1.
